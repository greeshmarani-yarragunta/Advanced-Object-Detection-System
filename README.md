# Advanced Object Detection System for Visually Impaired Using Deep Learning

## Project Overview
This project is an AI-powered real-time object detection system designed to assist visually impaired users. It detects objects using YOLO and OpenCV and provides voice alerts through Text-to-Speech (TTS) technology for safer navigation.

## Features
- Real-time object detection
- Live camera detection
- Upload image/video detection
- Voice alerts using Text-to-Speech
- User-friendly web interface

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Flask
- HTML
- CSS
- JavaScript
- Text-to-Speech (TTS)

## How to Run
1. Install the required Python libraries.
2. Run `main2.py`.
3. Open the application in your browser.
4. Use the live camera or upload an image/video for detection.
